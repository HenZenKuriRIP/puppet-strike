# 核心循环（0.1.14）

**核心循环（约 30–60 秒）**：读本波优先目标 → 走位/掩体 → 越肩瞄准射击 → 看前摇（红圈 / 激光）闪避 → 攻击结束后的硬直角可以集火或绕背 → 清波 → 三选一强化（可重随一次或跳过）→ 下一波组合变化。

**关卡循环（世界 1 约 6–10 分钟，视技术而定）**：1-1 与 1-2 各 3 波（每波有优先目标）→ 关卡奖励 → Boss 关（软糖国王）。通关 1-3 解锁世界 2，并解锁以后开局的一次自选强化。生存模式仍每 3 波给一次强化。

本文件取代早期“3 波、5 分钟会话、无成长”的 M1 描述。触控瞄准与相机不在本轮改动范围内。
