# 核心循环 & M1 计划

**核心循环（30 秒）**：观察波次 → 走位找糖果掩体 → 越肩瞄准扫射 → 读敌人前摇（地面红圈 / 红色激光）闪避 → 换弹窗口管理 → 清波 → 短暂喘息 → 下一波更难。

**会话循环（5 分钟）**：3 波 → 胜利/失败结算（分数）→ 立即重开。

1. 糖果竞技场（围栏、糖果方块掩体、棒棒糖、软糖、柔光阴影）

7. 3 波波次、胜负、重开、主菜单/设置/暂停、HUD
8. 纯逻辑单元测试
